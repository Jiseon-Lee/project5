## 🚩 개요
- 프로젝트 목표 : JSP/Servlet을 이용하여 웹 페이지 구현 및 DB연결
- 개발 기간 : 25/06/13 ~ 25/06/20

## 🛠️ 기술 스택
- Language : `JAVA(11)`, `JavaScript(1.5)`
- Framework : `JSP(JavaServer Pages)(2.3)`, `Servlet(4.0)`
- Database : `Mysql(8.0)`
- Server : `Apache Tomcat(9.0.70)`
- Tool : `Eclipse(4.29.0)`
- ETC : `Git`
